# Media authority

The logo is the owner-provided SVG at its native vector proportions. The story imagery is a local, role-named curation of the repository media inventory, rendered with explicit `next/image` `sizes`, blur placeholders, and deliberate object positions.

No external image URL is used at runtime. The source inventory was marked provisional in Phase 1, so the selected imagery remains pending production provenance approval. Two candidates with visible third-party vehicle marks were rejected and are not referenced by the public homepage. See `artifacts/frontend-phase2-signature/media-selection.json` for the scene map.
