# Responsive authority

The signature homepage has two compositions, not a scaled desktop:

- At 900px and above, the opening is a layered editorial spread; the handoff can pin; the media field is scroll-linked.
- Below 900px, the opening becomes a vertically staged photograph and reading sequence; handoff states stack; the media field becomes a native horizontal rail; network and coverage media move into the reading order.

Primary type uses controlled variable-font width and weight adjustments at the narrow breakpoint. Controls remain comfortably tap-sized, the header becomes a dialog-backed menu, and page-level horizontal overflow is prohibited.
