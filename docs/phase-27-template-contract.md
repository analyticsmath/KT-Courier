# Phase 27 template contract

Published template versions are immutable. Variables are bounded, typed, channel-scoped and escaped. The renderer accepts only `TEXT`, `REFERENCE`, `DATE`, `DATETIME`, `CURRENCY`, `INTEGER`, `BOOLEAN`, and `SAFE_INTERNAL_URL`; unknown, missing or unsafe values fail closed. Action routes are internal paths only. Restricted content uses the generic external body and never exposes evidence.
