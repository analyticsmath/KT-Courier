# Phase 19 storefront browsing

Phase 19 adds a read-only public marketplace shell behind a hard production
source lock. Public evidence can only be served from an eligible Phase 18
published snapshot projection. Browsing, search, category, product, variant,
store, collection, location-context and SEO implementations deliberately omit
carts, checkout, reservations, orders, payments and financial mutations.

The current user-facing `/shop` shell is intentionally polished but catalog
evidence remains unavailable until Phase 26.5 approves the source lock.
