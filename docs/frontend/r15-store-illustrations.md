# R15 — Store Illustration Map

R15 adds no new illustration. The existing R13 data-free SVGs are sufficient and avoid decorative art around active operational work.

| Component | State mapping | Semantics | Desktop/mobile use |
| --- | --- | --- | --- |
| `ParcelDeskIllustration` | Empty marketplace queue, empty courier-request list, empty product list | Decorative by default; no embedded text | Compact above empty-state copy; never behind a list/table |
| `SecureLedgerIllustration` | Empty earnings record list | Decorative by default; no amount or account data | Compact above financial empty-state copy |
| `AccessBoundaryIllustration` | Locked storefront, subscription, promotions, advertising | Decorative by default; the surrounding state supplies text | Compact protected-state panel at all widths |

All art uses the R13 carbon, mineral, oxide, and operational-teal palette. It has no gradients, purple, ivory, glossy/3D treatment, embedded text, fake products, customer data, external asset, or business metric. It is not placed behind forms, tables, dense queues, or active actions.
