# R18 — Developer Route Matrix

| Route ID | Exact path | Boundary | Owner context / authority | Permission | Safe DTO / composition | Canonical actions | Secret sensitivity / production lock | Mobile strategy / risk |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Public developer entry | `/developers` | Public Editorial Freight | Public contract guidance only | None | `DeveloperOverviewPage` | Sign in / OpenAPI link | No application data; public metadata retained | Public responsive page; no protected navigation |
| Documentation | `/developers/documentation` | Protected Editorial Operations | Customer or store integration owner | `developer_documentation.read` | Static contract-backed guidance | Download served OpenAPI | No secret; global live lock shown | Bounded code block |
| Applications overview | `/developers/applications` | Protected | Owner-scoped `DeveloperApplication` | `developer_application.read_own` | Safe application projection plus direct count projections | Create with `developer_application.manage_own` | No review evidence; live lock textual | Stacked application records |
| Application detail | `/developers/applications/[reference]` | Protected | Owner-scoped application, scope grants, terms date | `developer_application.read_own` | Safe application/scope/terms projection | Links only | No internal review evidence | One-column definition list |
| Application credentials | `/developers/applications/[reference]/credentials` | Protected | Owned application and credential metadata | `developer_credential.read_own` | Safe credential DTO fields | Create, rotate, revoke if existing owner permission allows | One-time secret only after POST response; live remains canonical-gated | Stacked credential records and bounded reveal |
| Application quota usage | `/developers/applications/[reference]/usage` | Protected | Owned quota records | `developer_api_usage.read_own` | Period/counter projection | None | No rate remaining/reset or forecast | Stacked records |
| Application request activity | `/developers/applications/[reference]/request-log` | Protected | Owned API audit metadata | `developer_api_usage.read_own` | request ID/method/template/status/time | None | No body/header/credential/Pii | Stacked records |
| Application webhooks | `/developers/applications/[reference]/webhooks` | Protected | Owned subscriptions | `developer_webhook.read_own` | Masked endpoint/status/events/times | Create with `developer_webhook.manage_own` | One-time signing secret after POST only | Stacked endpoints, form is one column |
| Credentials | `/developers/credentials` | Protected | Owner-scoped credentials across applications | `developer_credential.read_own` | Masked credential projection | Rotate/revoke under existing permissions | Never reads hash or full value | Stacked records |
| Webhooks | `/developers/webhooks` | Protected | Owner-scoped webhook subscriptions | `developer_webhook.read_own` | Masked endpoint projection | Detail navigation | No raw URL/challenge/secret | Stacked records |
| Webhook detail | `/developers/webhooks/[reference]` | Protected | Owned webhook subscription | `developer_webhook.read_own` | Masked endpoint/version/events/status | PATCH events, verify, pause/resume, revoke, rotate secret under manage permission | Signing secret one-time only; live rules remain canonical | One-column record and local event list |
| Webhook deliveries | `/developers/webhooks/[reference]/deliveries` | Protected | Owned delivery metadata | `developer_webhook_delivery.read_own` | Event/endpoint/state/attempt/time | Detail navigation | Metadata only; no payload/headers/signature | Stacked delivery records |
| Delivery detail | `/developers/webhook-deliveries/[reference]` | Protected | Owned delivery and canonical attempts | `developer_webhook_delivery.read_own` | Safe attempt projection | Retry only with retry permission and `FAILED_RETRYABLE` state | No next retry time, payload or secret | Ordered one-column timeline |
| Usage and quotas | `/developers/usage` | Protected | Owner-scoped quota/request projections | `developer_api_usage.read_own` | Recorded counter and request metadata | None | Rate-window state absent; no derived numbers | Stacked records |

The mandatory catch-all preserves other pre-existing deeper segment matches only as a protected “route unavailable” state. It does not create a new action workflow, expose a generic router console, or treat unknown paths as a healthy resource.
