# R23 — Marketplace route matrix

| Exact path | Route parameter | Canonical href builder | Loader / publication state | Browsing and transaction lock | Final composition / mobile strategy | Completion evidence |
| --- | --- | --- | --- | --- | --- | --- |
| `/shop` | — | `marketplaceHref()` | `getStorefrontHome()`; category/store/product public projections | Browsing resolves projections; no checkout query. | Market Hall header, server-backed search and cards; stacked compact sections. | Landing and homepage cards call shared card helpers. |
| `/shop/categories` | — | `marketplaceCategoriesHref()` | `listStorefrontCategories()`; published category documents. | No global browse placeholder; empty directory is a truthful source-empty state. | Breadcrumb, directory rail; horizontal compact rail / desktop grid. | `MarketplaceCategoryRail` calls `marketplaceCategoryHref()`. |
| `/shop/categories/[...categoryPath]` | `categoryPath: string[]` | `marketplaceCategoryHref(path)` | Validate path → `getStorefrontCategory()` → server search with category filter. | Missing/non-public → not-found; cart lock never read. | Breadcrumb, identity, description, trusted media, children, filters/sort/list/pagination, empty state. | Focused R23 route test checks loader and no unavailable interception. |
| `/shop/stores` | `q?: string` | `marketplaceStoresHref(query)` | `listStorefrontStores()`; active public store documents only. | No global browse placeholder. | Breadcrumb, bounded store-name search, semantic cards; one-column compact / three-column desktop. | `MarketplaceStoreGrid` calls `marketplaceStoreHref()`. |
| `/shop/stores/[storeSlug]` | `storeSlug: string` | `marketplaceStoreHref(slug)` | Validate slug → `getStorefrontStore()` → public category resolution + server store search. | Missing/non-public → not-found; active empty store stays viewable; checkout lock separate. | Cover/logo/identity/categories/catalogue; cover then identity/catalogue on compact screens. | Focused R23 route test checks loader and empty copy. |
| `/shop/stores/[storeSlug]/categories/[...categoryPath]` | `storeSlug`, `categoryPath: string[]` | `marketplaceStoreCategoryHref()` | Public store and category loaders; supplied relationship must match. | Invalid relation/missing record → not-found. | Store-category result listing with truthful empty state. | Shared listing helper and relationship check. |
| `/shop/products/[product]` | `product: slug-CP-*` | `marketplaceProductHref(slug, reference)` | Validate parameter → `getStorefrontProduct()`; active product projection and slug match. | Missing/non-public → not-found; availability does not hide the record; purchase remains locked separately. | Breadcrumb, LCP primary media, store link, ZAR price, availability, variant links/offers, related lists. | Product parameter helper, media fallback, semantic list checks. |
| `/shop/products/[product]/[variantReference]` | product parameter + `CV-*` | `marketplaceVariantHref()` | Validate references → `getStorefrontVariant()`; active document and slug match. | Missing/non-public → not-found; purchase remains locked separately. | Variant primary media, price, availability, options and offer/store links. | Variant helper and loader checks. |
| `/shop/search` | Validated query/filter object | `marketplaceSearchHref()`, `marketplaceListingHref()` | `StorefrontSearchService`; optional suggestions re-resolved through public category/store loaders. | Search noindex; no global browse placeholder. | Query context, continuations, facets/sort/list/cursor; compact filter disclosure. | Shared listing helper and source-authority checks. |
| `/shop/collections` | — | `marketplaceCollectionsHref()` | No public directory projection exists. | No artificial records; no browse placeholder. | Truthful continuation to search. | No fake collection data. |
| `/shop/collections/[collectionSlug]` | `collectionSlug: string` | `marketplaceCollectionHref(slug)` | Active collection + active canonical targets only. | Missing/non-public → not-found. | Canonical product/variant/category/store target links. | Shared detail builders only. |
| `/cart` | — | `marketplaceCartHref()` | Existing cart boundary; no public cart display DTO. | `CHECKOUT_PRODUCTION_LOCK` retained. | Noindex truthful unavailable state. | Existing cart boundary source assertion. |
| `/checkout` and descendants | Checkout-owned opaque reference | `marketplaceCheckoutHref()` for entry | Existing checkout authority. | Checkout/payment/auth locks retained. | Existing noindex transaction states. | Existing checkout boundary source assertion. |

All builders accept only internal, validated source values. They do not receive a host, arbitrary path, or redirect target. `canonicalStorefrontQuery()` serializes supported server filters, sorting, and cursor state without client pathname guessing.
