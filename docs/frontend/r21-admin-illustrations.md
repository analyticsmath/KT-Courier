# R21 administration illustrations

R21 adds no new illustrations. Finance, programme, platform, notification and
governance states are evidence-heavy operational surfaces where decorative art
would obscure locked, unavailable, empty, reconciliation-required or
restricted states. The existing protected-state treatment is used instead.

No custom illustration asset, remote image, gradient treatment, fabricated
chart, or decorative financial visual is introduced in this phase.

The reused protected-state semantics are empty, unavailable, restricted, locked
and error. Their palette is the existing restrained operational/status palette;
state text is always present so colour is not the sole signal. The same semantic
state is used on desktop and mobile. Decorative illustrations are prohibited in
financial queues, permission review, recruitment evidence, developer secret
contexts and notification-delivery diagnosis.
