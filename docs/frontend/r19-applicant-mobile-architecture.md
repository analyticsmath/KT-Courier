# R19 mobile architecture

The Candidate Dossier has a compact identity bar, a skip link, one main landmark, and one-column application sections below 600px. Long route links wrap; no account navigation, KPI tiles, desktop table, bottom navigation, or browser-persistent draft is used. Native upload, slot selection, software-keyboard form validation, and offer confirmation are deferred because safe canonical client contracts are absent. UTC is explicit for any scheduled interview time.
