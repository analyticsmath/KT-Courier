# R18 — Developer Illustrations

## Reused R13 illustrations

R18 reuses `AccessBoundaryIllustration` only when a protected developer route is unavailable or permission-restricted. It retains the R13 carbon, cool-neutral, oxide and restrained operational-teal palette and semantic alternative behavior.

## New R18 illustrations

No new developer-specific illustration was created. The verified portal is a dense record and security workspace; an illustration would not improve application, credential, webhook or delivery decisions. This remains within the four-illustration limit.

## State mapping and use

The reused access-boundary illustration may appear on unavailable/restricted server states, once per route. It is not used as a generic dashboard decoration, in a secret reveal, beside a production lock, in navigation, or in a table row. On mobile it remains subordinate to the state copy and never forces horizontal overflow.

## Prohibited usage

No illustration may contain embedded text, credentials, signing secrets, customer data, external logos, fake terminals, code windows, charts, robots, crypto imagery, gradients, purple, glossy 3D treatment or a health/uptime claim.
