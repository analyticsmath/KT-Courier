# Customer and public journey evidence

The canonical public route set observed on the existing site includes `/`, `/quote`, `/shop`, `/shop/stores`, `/shop/search`, `/login`, `/contact` and `/services/parcel`. Each returned HTTP 200 in the read-only baseline probe. The apex returned 308 to `www`. Those checks prove liveness for the older deployed build only; they are not a Phase 3 transaction or customer acceptance.

The current source contains the public quote, customer identity, marketplace checkout, guest contact verification, order, wallet and refund journeys. Relevant exact-source automation is in `tests/e2e/anonymous-courier-quote.spec.ts`, `tests/e2e/customer-identity-lifecycle.spec.ts`, `tests/e2e/marketplace-checkout-guest.spec.ts`, `tests/e2e/marketplace-checkout-payment.spec.ts`, `tests/e2e/customer-wallet-refunds.spec.ts` and `tests/e2e/transactional-notifications.spec.ts`. Hosted run [38247409666](https://github.com/analyticsmath/KT-Courier/actions/runs/38247409666) is bound to tested source `f30d2feb2172c32c709b4f0e173595eabe138d00`; directed, finance, Paystack, full Chromium and canonical PostgreSQL selections passed with zero failures, skips or flakes. This automation does not replace human product acceptance or commercial activation approval.

Do not treat historical rates, available parcel sizes, coverage, COD eligibility or service guarantees as currently activated customer promises. Their owner-approved versions are absent. Anonymous tracking routes such as `/track` are not confirmed canonical routes; authenticated order history is under `/account/orders`.
