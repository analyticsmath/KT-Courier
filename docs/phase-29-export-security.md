# Phase 29 Export Security & Anti-Formula Injection Specification

## Security Rules & Mitigations

### 1. CSV Anti-Formula Injection
CSV files generated by the reporting engine are automatically passed through `sanitizeCsvValue()` in `lib/reporting/csv-sanitizer.ts`.
- Any cell value beginning with `=`, `+`, `-`, `@`, `\t`, or `\r` is prefixed with a single quote (`'`).
- Prevents remote command execution or dynamic data exfiltration via Excel / LibreOffice macro triggers.

### 2. Download Security
- Reports are stored in an unexposed internal location (`storage/reports/`).
- Direct file access via public web server URL is strictly forbidden.
- Download URLs are generated using HMAC-SHA256 signatures with a 15-minute expiration timestamp (`exp`).
- Artifact download requests verify SHA-256 integrity checksums against recorded database evidence before serving stream bytes.

### 3. Tenant Data Scoping
- All projections enforce tenant owner scoping (`ownerScope`).
- A Store user can only request reports where `storeId` matches their authenticated store.
- A Driver user can only request reports where `driverProfileId` matches their authenticated driver profile.
- A Customer user can only request reports where `customerUserId` matches their account ID.
